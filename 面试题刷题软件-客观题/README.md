# 面试题刷题软件 · 客观题

> **版本：2.3.1（面试题库版）**（2026-09-13）
> 题库：**面试题库 · 客观题** —— 单选 171 + 多选 5 + 判断 35 + 特殊题 2 = **213 题**
> （来源：2022~2026 全部面试试卷整理，含答案与**逐题完善后的解析**；`题库/01_客观题_选择题.md`）

界面风格类似软考通：**单选 / 多选 / 判断自动判分**，带解析、错题本、笔记、模拟考试。

## 快速开始

1. 双击 **`启动刷题软件.bat`**（自动定位 Python；若缺 `题库.json` 会自动从 `题库/` 生成）
2. 或命令行：`python core/build_bank.py` 生成题库 → `python core/刷题软件.py` 打开

## 题库更新 / 切换（支持 md 与 docx）

程序识别 **单选题 / 多选题 / 判断题 / 特殊题**：

1. 把 **题库文档**（自带答案）放进 **`题库/`** 文件夹（可放多个用于切换）：
   - `01_客观题_选择题.md`（当前题库；md 需带「**答案：…**」行）
   - 或自带答案的 Word 题库（`*.docx`，兼容原解析器）
2. 双击 **`更新题库.bat`** → 选择文档 → 自动解析并覆盖 `题库.json`
3. 重新打开刷题软件即可

## 功能

| 功能 | 说明 |
|---|---|
| **三种模式** | 顺序练习 / 错题重做 / 模拟考试 |
| **题型标注** | 题干上方显示 **[单选题/多选题/判断题 N]**，考试中同样标注，多选作答区有明确提示 |
| **多选交互** | 点击可多选、再点取消（选中行变蓝）；点「确认答案」判分，**全对才正确** |
| **单选/判断** | 选中整行变蓝 → 点「确认答案」判分；判断题先选 ✔/✘ 不锁定 |
| **🎓 模拟考试** | 40 分钟 / 30 题（**选择题 20（含多选）+ 判断 10**）/ 每题 5 分，满分 150；**环形抽题：同一场绝不重复，连续 9 场必覆盖全部 176 道选择题、4 场覆盖 35 道判断题**（选择题与选项均随机打乱） |
| **考试控制** | 暂停/继续、退出；考试中禁止切换板块、禁止打开笔记；强制关闭自动保存、下次打开恢复 |
| **考试题号导航** | 未答白 / 答对绿 / 答错红，点击直接跳转；交卷后点题号进入该题回顾 |
| **错题本** | 答错（含考试中）自动进入；重做答对自动移出；累计错误次数 |
| **📝 笔记** | 独立窗口（可缩放），切换题目自动跟随，自动保存 |
| **🗑 重置进度** | 连续 3 次确认 + 最后 5 秒冷静期 |
| **特殊题** | 存疑 / 写结果类（第 112、17 题）显示原卷选项 + 「查看答案」+ 掌握标记，不判分 |
| **题目配图** | 带图题（第 96、136 题）自动显示原卷裁剪图（最大 600px 自适应缩放；有 PIL 平滑缩放，无则原生缩放） |
| **长内容不丢** | 超长题干/选项/解析自动增高，超限出现滚动条；选项区可滚动（鼠标滚轮）；窗口缩放时排版自动跟随，标签宽度自适应 |
| **窗口自适应** | 按屏幕尺寸自动定窗口大小并居中（小屏不超出）；高分屏 DPI 感知清晰显示 |
| **键盘快捷键** | ◀/▶ 翻题、回车=确认答案、1-4 / A-D 快速选选项（打字时自动让位） |
| **答案保密** | 作答前界面绝不出现答案 |

  - **笔记窗口加大**（按屏幕比例，默认更大、位置靠右；可自由缩放）
