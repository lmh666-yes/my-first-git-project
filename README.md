> **版本：1.0.7**（2026-08-20）· 全量自动化测试通过 · 跨电脑拉取即可运行

这个仓库是 C/C++ 学习与开发的一站式工具箱，包含**三个子项目**：

| 子项目 | 作用 | 一句话说明 |
|---|---|---|
| **`01函数库/`** | 纯 C 函数库（1179 个函数/宏） | 数组、字符串、数据结构、算法、图、哈希…拿来即用的 C 函数库 + 图形化查找工具 + 一键部署 |
| **`02数据结构/`** | C/C++ 代码可视化器 | 把你写的链表/树/数组/递归代码**逐步执行**，画出每一步的内存状态与结构图，直观理解指针 |

## 1️⃣ 01函数库 — 纯 C 函数库

一个 **1179 个函数/宏**的纯 C 函数库，覆盖数组、字符串、数学、数论、排序、查找、位运算、数据结构（链表/单循环链表/栈/队列/环形缓冲区/动态数组/优先级队列/二叉搜索树/并查集/双端队列/堆）、哈希、图算法（BFS/DFS/Dijkstra/拓扑排序/Prim）、回调函数、变参函数、复合函数、CRC、进制转换、时间日期、随机、几何、矩阵、文件、内存、系统工具等领域。

- **一键部署**：双击 `01函数库/install_my_lib.bat`，自动定位 MinGW 并安装为静态库 `libmylib.a`
- **图形化查找**：`01函数库/programs/utils_gui.exe` 支持搜索、74 分类筛选、排序、复制、跳转 VS Code
- 详细说明见 **`01函数库/README.md`**

```c
#include <utils.h>
#include <multifunc.h>     // 可选
// 编译链接: gcc 你的程序.c -lmylib -o 程序
```

## 2️⃣ 02数据结构 — C/C++ 代码可视化器

把一段 **C/C++ 代码**（链表、树、数组、递归等）放进来，程序会**识别并逐步执行**，
把每一步的**内存状态**（堆块、指针、箭头）和**链表/树结构**画成图。
点击左侧代码的任意一行，右侧立刻显示**该行执行之后**的正确状态图。

- 双击 `02数据结构/启动可视化器.bat` 或运行 `python visualizer.py`
- **内存可视化**：黄色=堆(malloc)、绿色=栈上结构体；指针用箭头精确指向目标，NULL 指向 NULL 标记
- **逐步模拟（pythontutor 式）**：上一步 / 下一步逐行回放，函数递归显示完整调用栈
- **交互**：拖动平移、Ctrl+滚轮缩放、双击复位、点击内存块查看“属于哪个变量 + 当前状态”
- **野指针/已释放内存**会标红警告，代码有问题也能从内存图看出来
- 详细说明见 **`02数据结构/README.md`**

```bash
cd 02数据结构
python visualizer.py
```

## 3️⃣ C刷题软件 — 软考通式刷题软件

从 Word 题库（`原题目.docx` + `原题目答案.docx`）自动生成题库的刷题程序，
界面风格类似软考通。题库内容为 **嵌入式软件开发工程师（中级）**：
单选 80 题 + 判断 50 题，共 **130 题**。

- **一键启动**：双击 `C刷题软件/启动刷题软件.bat`（自动定位 Python；缺 `题库.json` 会自动从 docx 生成）
- **四种模式**：顺序练习 / 随机练习 / 错题重做 / 模拟考试（随机 20 题限时）
- **作答**：单选判分+解析；判断一键判分；答错自动进错题库并累计错误次数，反馈框显示「累计错误 N 次」
- **📝 笔记**：题目右侧笔记框可写可改，自动保存，下次做到该题自动显示
- **🗑 清除记忆**：底部「重置进度」一键清空做题记录 / 错题次数 / 笔记
- **统计与进度**：顶部实时统计正确率与错题数，作答与笔记自动保存 `progress.json`，下次打开恢复
- **健壮性**：题库损坏/缺失/缺字段、进度文件损坏均不崩溃（有压力测试 + 崩溃测试）
- 详细说明见 **`C刷题软件/README.md`**
