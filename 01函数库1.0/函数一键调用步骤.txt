================================================================
                UTILS 函数库 · 使用与部署说明
================================================================

【目录结构】（按 库函数 / 程序 / 测试 三类组织）
  library\   库函数类（核心函数库）
     utils.h          主头文件（#include <utils.h>）
     utils.c          主实现
     utils_gen.h      自动生成的函数声明（已由 utils.h 自动包含）
     utils_gen.c      自动生成的函数实现（已由 utils.c 自动包含）
     func_index.h     函数索引表（供查找工具使用，勿手改）
     gen_functions.py 函数批量生成器（扩充函数 + 重建索引用）
     multifunc.h / multifunc.c  多功能执行器（可选库）
  programs\   程序类
     utils_gui.exe    图形化查找工具（双击即可用）
     utils_gui.c      源码
     build_gui.bat    重新编译图形化工具（注意：以 GBK 编码保存）
     theme.ini        主题配色配置（可自定义高亮颜色）
     main.c           Hello World 示例
  tests\      测试函数类
     test_lib.c       库测试演示程序（部署后可直接编译运行）
     test_extra.c     新增数据结构/算法/宏测试
     verify_install.c 部署验证程序（install_my_lib.bat 会自动调用）
     uti-main.c       utils 全部函数演示程序
     mul-main.c       multifunc 演示程序
  根目录\
     install_my_lib.bat  一键部署到 MinGW（推荐，双击运行）
     函数一键调用步骤.txt  本说明文档

================================================================
一、一键部署（把函数库装进 MinGW，推荐）
================================================================
  双击运行根目录的  install_my_lib.bat
  或在命令行执行：
    cd 01函数库1.0
    install_my_lib.bat

  脚本会自动：
    1. 找到 MinGW 安装位置
    2. 复制 utils.h / utils_gen.h / func_index.h / multifunc.h 到头文件目录
    3. 编译 utils.c + multifunc.c，打包成静态库 libmylib.a 并复制到库目录
    4. 在临时目录编译运行 verify_install.c，验证任意目录可直接调用

================================================================
二、在自己的程序里调用（部署后）
================================================================
  源码开头包含头文件：
    #include <utils.h>
    #include <multifunc.h>      // 这是 library 里的另一个库（可选）

  编译链接：
    gcc your_program.c -lmylib -o program
        (程序名)      (固定库名)   (输出文件名)

  函数库共 1157 个函数/宏，覆盖：
    数组 / 字符串 / 数学 / 数论 / 排序 / 查找 / 位运算 /
    链表（含单循环链表进阶）/ 栈 / 队列 / 环形缓冲区 / 动态数组 / 优先级队列 /
    二叉搜索树 / 并查集 / 哈希函数 / 图算法 / CRC校验 / 进制转换 /
    时间日期 / 随机 / 几何 / 矩阵 / 文件 / 内存 / 系统工具 等

================================================================
三、快速查找函数（图形化工具 v2.0）
================================================================
  双击  programs\utils_gui.exe
  功能：
    - 搜索框实时过滤：支持模糊查找（子序列匹配，如 bs → bubble_sort）、
      空格分隔多关键词、不区分大小写，结果按匹配度排序
    - 分类下拉框：按 67 个分类筛选，每项标注函数数量
    - 列表排序：点"按名称排序/按分类排序"按钮，或直接点列标题
    - 单击函数 → 右侧显示功能说明、调用示例、源码位置和实现源码
    - 详情包含"详细说明"：展示函数参数（@param）、返回值（@return）等注释，
      显示在实现源码下方（绿色注释风格）
    - 实现源码按 Notepad++ 风格语法高亮（白底黑字，关键字蓝、注释绿、
      字符串灰等，配色可在 theme.ini 中修改）
    - 左侧列表三态高亮：鼠标悬停亮色、点击选中深色（失焦后变淡但仍可见）、
      普通行白/灰条纹
    - 核心算法函数（排序/查找/链表/队列等）源码内已添加关键步骤中文注释，
      方便初学者理解实现思路
    - 双击函数 / 点[打开实现] → 跳转 VS Code 到实现行
    - 点[打开声明] → 跳转 VS Code 到声明行
    - [复制函数名] / [复制示例] / [复制实现源码]：一键复制到剪贴板
    - 支持全部 1110 个函数（含 utils_gen.h / utils_gen.c 自动生成区）
      以及 5 个常用宏（显示宏定义并可跳转）

================================================================
四、常见问题（乱码与重新编译）
================================================================
  1. build_gui.bat 必须保持 GBK(ANSI) 编码保存，不要另存为 UTF-8，
     否则在 cmd 中运行时中文会乱码。
  2. utils_gui.c / utils.h / utils.c / func_index.h 等源码均为 UTF-8 编码；
     重新编译图形化工具请直接双击 build_gui.bat（内部已带
     -finput-charset=UTF-8 -fexec-charset=GBK），保证界面中文正常显示。
  3. 运行 utils_gui.exe 时，它会自动在 exe 同目录 / ..\library / ..\lib
     / 当前目录等位置查找 utils.h、utils_gen.h、utils.c、utils_gen.c
     四个文件（推荐结构：programs\utils_gui.exe + library\ 四个文件）。
  4. 修改 utils.h / utils_gen.h 后若函数列表没有更新，可在 library 目录运行：
        py gen_functions.py
     它会自动重建 func_index.h（同时会重新生成自动函数，运行前请先确认）。
