================================================================
                UTILS 函数库 · 使用与部署说明
================================================================

【目录结构】
  lib\     函数库内容 + 一键部署脚本
     utils.h          主头文件（#include <utils.h>）
     utils.c          主实现
     utils_gen.h      自动生成的函数声明（已由 utils.h 自动包含）
     utils_gen.c      自动生成的函数实现（已由 utils.c 自动包含）
     func_index.h     函数索引表（供查找工具使用，勿手改）
     gen_functions.py 函数批量生成器（扩充函数用）
     install_my_lib.bat  一键部署到 MinGW（推荐）
     uti-main.c       全部函数演示程序
  tools\   函数查找程序（图形化）
     utils_gui.exe    图形化查找工具（双击即可用）
     utils_gui.c      源码
     build_gui.bat    重新编译图形化工具

================================================================
一、一键部署（把函数库装进 MinGW，推荐）
================================================================
  双击运行  lib\install_my_lib.bat
  （或运行根目录的 install_my_lib.bat，效果相同）
  或在命令行执行：
    cd lib
    install_my_lib.bat

  脚本会自动：
    1. 找到 MinGW 安装位置
    2. 复制 utils.h / utils_gen.h / func_index.h / multifunc.h 到头文件目录
    3. 编译 utils.c + multifunc.c，打包成静态库 libmylib.a 并复制到库目录
    4. 在临时目录编译运行 verify_install.c，验证任意目录可直接调用

================================================================
二、在自己的程序里调用（部署后）
================================================================
  源码开头包含头文件：
    #include <utils.h>
    #include <multifunc.h>      // 这是 framework 里的另一个库（可选）

  编译链接：
    gcc your_program.c -lmylib -o program
        (程序名)      (固定库名)   (输出文件名)

  函数库共 1100+ 个函数，覆盖：
    数组 / 字符串 / 数学 / 数论 / 排序 / 查找 / 位运算 /
    链表 / 栈 / 队列 / 环形缓冲区 / 动态数组 / 优先级队列 /
    二叉搜索树 / 哈希表 / 图算法 / CRC校验 / 进制转换 /
    时间日期 / 随机 / 几何 / 矩阵 / 文件 / 内存 / 系统工具 等

================================================================
三、快速查找函数（图形化工具）
================================================================
  双击  tools\utils_gui.exe
  功能：
    - 顶部搜索框实时过滤，可按下拉框按 31 个分类筛选
    - 单击函数 → 右侧显示功能说明、调用示例、源码位置和实现代码
    - 双击函数 → 自动在 VS Code 中打开 utils.c 对应实现行
    - 按钮"打开实现/打开声明"可跳转头文件声明或源码实现
