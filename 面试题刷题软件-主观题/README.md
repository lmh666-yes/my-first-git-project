# 面试题刷题软件 · 主观题

> **版本：2.5.1**（2026-09-16）
> 题库：**面试题库 · 主观题** —— 填空 / 简答 / 计算 / 写结果 / 文字代码分析，共 **423 题**（已全库查重去重）
> （来源：2022~2026 全部面试试卷 + `附加面试题`（面试题4 / 笔试题1 / 笔试题3 / 欣诺通信）整理，参考答案与得分点已逐题提质；`题库/02_主观题.md`）
> **只有纯文字题与「文字 + 代码分析」题**（求结果、找错、改错、评论代码、概念简答）。
> 需要**写代码**或**看图 / 画图**的题已全部收在 **`题库/03_编程画图大题.md`**（33 题迁出 + 73 题大题汇编 + 15 题附加面试题 = **121 题**，编号 401~495）。

**打字作答、不判对错**：每题输入框打字自测 → 「查看参考答案」对照 **答案 + 得分点**。
含**模拟考试（10 题 / 40 分钟）**：交卷后逐题回顾对照答案自评；无错题库。

## 快速开始

1. 双击 **`启动刷题软件.bat`**（自动定位 Python；若缺 `题库.json` 会自动从 `题库/` 生成）
2. 或命令行：`python core/build_bank.py` 生成题库 → `python core/主观题软件.py` 打开

## 功能

| 功能 | 说明 |
|---|---|
| **顺序浏览** | 上一题 / 下一题，覆盖全部 423 题 |
| **🧠 进度记忆** | 打开软件自动跳到「**连续完成题目的最后一题**」：做了 1、2、3、4，跳过 5 又做了 6、7、8，下次打开就在**第 4 题**（题头显示「↩ 已回到上次进度」）；切到考试再回来则回到刚才浏览的位置 |
| **✍️ 打字作答** | 每题输入框，**自动保存**；切题、关闭程序均不丢失 |
| **👀 查看参考答案** | 一键显示 **参考答案 + 得分点**（分色），再点「收起」隐藏 |
| **跳题** | 顶栏输入题号回车，直达任意题 |
| **统计** | 顶部实时显示 **已看答案 x/366 · 已作答 y/366** |
| **🎓 模拟考试** | 每次 **10 题 / 40 分钟**；**环形抽题：同一场绝不重复，连续多场必覆盖全部 423 题**（每题间隔 ≤40 场）；暂停/退出/恢复；**交卷后逐题回顾**（我的作答 + 参考答案 + 得分点）自评 |
| **长内容不丢** | 超长题干/参考答案自动增高，超限出现滚动条；窗口按屏幕自适应并居中；高分屏 DPI 感知；◀/▶ 翻题快捷键 |
| **🗑 重置进度** | 连续 3 次确认 + 最后 5 秒冷静期 |
| **不打分** | 无对错、无错题库 |

## 题库更新 / 切换

1. 把 **02 风格 md 题库**（每题带「**参考答案：**」与「**得分点：**」行）放进 **`题库/`** 文件夹（可放多个用于切换）
2. 双击 **`更新题库.bat`** → 选择文档 → 自动解析并覆盖 `题库.json`
3. 重新打开刷题软件即可

> 题库文件夹里现在有两份：`02_主观题.md`（423 题，默认）与 `03_编程画图大题.md`（121 题）。
> 想专门练**编程 / 画图大题**时，用「更新题库」选择 `03_编程画图大题.md` 即可把它导入软件（作答方式一样：打字 → 对照参考答案）。
