# C 语言刷题软件

> **版本：1.0.9**（2026-08-20）· 自检 28 项 / 压力 14 项 / 崩溃 17 项全部通过

基于 Word 题库（**单文件、自带答案**）自动生成的刷题程序，界面风格类似软考通。
题库内容为 **嵌入式软件开发工程师（中级）**：单选 80 题 + 判断 50 题，共 **130 题**（含代码题）。

## 快速开始

1. 双击 **`启动刷题软件.bat`**（自动定位 Python；若缺 `题库.json` 会自动从 Word 文档生成）
2. 或命令行：`python build_bank.py` 生成题库 → `python 刷题软件.py` 打开

## 题库来源

- **`嵌入式软件开发（中级）题库（含答案）.docx`**：题目自带答案，`build_bank.py` 解析后生成 `题库.json`（答案只存后台，答题界面绝不提前显示）
- 题目与答案**逐题核对、100% 忠实原文**（含代码题完整代码、判断题 5 题一组共享答案串、带/不带 A-D 前缀选项、制表符分隔选项等特殊格式均已处理）

## 功能

| 功能 | 说明 |
|---|---|
| **四种模式** | 顺序练习 / 随机练习 / 错题重做 / 模拟考试 |
| **🎓 模拟考试** | 右上角「开始考试」→ 20 分钟 / 20 题 / 每题 5 分；交卷出成绩 |
| **考试控制** | 考试中右上角可**暂停/继续**、**退出**；**禁止切换其他板块**（有提醒） |
| **考试中断恢复** | 强制关闭程序自动保存，下次打开**直接回到考试板块**继续；点 X 关闭有「正在考试」提醒 |
| **错题回顾** | 交卷后页面显示**错题号按钮**（每行 6 个自动换行，不挤在一起），点击查看该题与答案 |
| **错题本** | 答错（含考试中答错）自动进入错题库；每题累计错误次数 |
| **📝 笔记** | 题目右侧笔记框可写可改，自动保存，下次做到该题自动显示 |
| **🗑 重置进度** | 底部「重置进度」：**连续 3 次确认 + 最后 5 秒冷静期**后才清除全部记忆 |
| **答案保密** | 题目自带答案仅存后台，作答前界面绝不出现答案（已全量 130 题验证） |
| **统计** | 顶部实时显示已做/总数、正确率、错题数 |
| **收藏** | ⭐ 收藏任意题目 |

