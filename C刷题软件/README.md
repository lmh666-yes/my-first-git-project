# C 语言刷题软件

> **版本：1.0.8**（2026-08-20）· 自检 28 项 / 压力 14 项 / 崩溃 17 项全部通过

基于 Word 题库（`原题目.docx` + `原题目答案.docx`）自动生成的刷题程序，界面风格类似软考通。
题库内容为 **嵌入式软件开发工程师（中级）**：单选 80 题 + 判断 50 题，共 **130 题**。

## 快速开始

1. 双击 **`启动刷题软件.bat`**（自动定位 Python；若缺 `题库.json` 会自动从 docx 生成）
2. 或命令行：`python build_bank.py` 生成题库 → `python 刷题软件.py` 打开

## 功能

| 功能 | 说明 |
|---|---|
| **四种模式** | 顺序练习 / 随机练习 / 错题重做 / 模拟考试 |
| **🎓 模拟考试** | 右上角「开始考试」→ 20 分钟 / 20 题 / 每题 5 分；交卷出成绩 |
| **考试控制** | 考试中右上角可**暂停/继续**、**退出**；**禁止切换其他板块**（有提醒） |
| **考试中断恢复** | 强制关闭程序自动保存，下次打开**直接回到考试板块**继续；点 X 关闭有「正在考试」提醒 |
| **错题回顾** | 出成绩后在页面显示**错题号按钮**，点击查看该题题目与正确答案 |
| **错题本** | 答错（含考试中答错）自动进入错题库；每题累计错误次数，反馈框显示「累计错误 N 次」 |
| **📝 笔记** | 题目右侧笔记框可写可改，自动保存，下次做到该题自动显示 |
| **🗑 重置进度** | 底部「重置进度」：**连续 3 次确认 + 最后 5 秒冷静期**后才清除全部记忆 |
| **统计** | 顶部实时显示已做/总数、正确率、错题数，进度条实时更新 |
| **收藏** | ⭐ 收藏任意题目 |

## 文件说明

```
C刷题软件/
├── 原题目.docx          题目（去除答案）
├── 原题目答案.docx      答案
├── build_bank.py        解析 docx → 生成 题库.json（仅单选+判断）
├── 题库.json            解析后的题库数据（可重新生成）
├── 刷题软件.py          GUI 主程序
├── 启动刷题软件.bat      一键启动
├── test_brust.py        自检（28 项）
├── test_stress.py       压力测试（14 项）
├── test_crash.py        崩溃测试（17 项）
└── progress.json        进度+错题次数+笔记+考试会话（自动生成，已 git 忽略）
```
