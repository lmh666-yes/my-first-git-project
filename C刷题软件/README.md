# C 语言刷题软件

> **版本：1.0.6**（2026-08-20）· 自检/压力/崩溃测试全部通过

基于 Word 题库（`原题目.docx` + `原题目答案.docx`）自动生成的刷题程序，界面风格类似软考通。
题库内容为 **嵌入式软件开发工程师（中级）**：单选 80 题 + 判断 50 题 + 简答/编程 11 题，共 141 题。

## 快速开始

1. 双击 **`启动刷题软件.bat`**（自动定位 Python；若缺 `题库.json` 会自动从 docx 生成）
2. 或命令行：`python build_bank.py` 生成题库 → `python 刷题软件.py` 打开

## 功能

| 功能 | 说明 |
|---|---|
| **四种模式** | 顺序练习 / 随机练习 / 错题重做 / 模拟考试（随机 20 题限时） |
| **单选** | 点选项 →「确认答案」→ 判对错 + 显示正确答案与解析 |
| **判断** | 点「✔正确 / ✘错误」→ 立即判分 |
| **简答/编程** | 自行作答 →「查看答案」对照 →「已掌握/还需复习」标记 |
| **统计** | 顶部显示已做/总数与正确率，进度条实时更新 |
| **收藏** | ⭐ 收藏任意题目 |
| **错题本** | 「错题」模式自动只练错题；「重新做题」可清除单题记录 |
| **进度保存** | 作答记录自动保存到 `progress.json`，下次打开自动恢复 |

## 文件说明

```
C刷题软件/
├── 原题目.docx          题目（去除答案）
├── 原题目答案.docx      答案
├── build_bank.py        解析 docx → 生成 题库.json
├── 题库.json            解析后的题库数据（可重新生成）
├── 刷题软件.py          GUI 主程序
├── 启动刷题软件.bat      一键启动
├── test_brust.py        自检（18 项）
├── test_stress.py       压力测试（12 项）
├── test_crash.py        崩溃测试（14 项）
└── progress.json        作答进度（自动生成）
```

## 重新生成题库

题库来自 Word 文档，若文档更新，重新运行：

```bash
python build_bank.py
```

会重新解析 `原题目.docx` / `原题目答案.docx` 并覆盖 `题库.json`。
