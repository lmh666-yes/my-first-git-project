# C 语言刷题软件

> **版本：1.2.1**（2026-08-21）· 自检 28 / 压力 14 / 崩溃 17 / 扩展 23 / 更新题库 17 项全部通过

基于 Word 题库（**自带答案**）自动生成的刷题程序，界面风格类似软考通。
**支持多种题库自由切换**：把任意 Word 题库文档放进 `题库/` 文件夹，双击「更新题库」即可切换。

## 快速开始

1. 双击 **`启动刷题软件.bat`**（自动定位 Python；若缺 `题库.json` 会自动从 `题库/` 文件夹生成）
2. 或命令行：`python build_bank.py` 生成题库 → `python 刷题软件.py` 打开

## 题库切换（核心功能）

程序只识别 **单选题** 和 **判断题** 两类题目，切换题库方法：

1. 把 **Word 题库文档（自带答案）** 放进 **`题库/`** 文件夹（可放多个，用于不同科目/不同试卷切换）
2. 双击 **`更新题库.bat`**
3. 若文件夹里有多个题库文档，会列出清单让你**输入编号选择**；只有一个则直接使用
4. 自动解析 → **覆盖生成 `题库.json`** → 显示题数统计
5. 重新打开刷题软件即可使用新题库

支持格式：题干可含多行代码（完整保留）、选项带/不带 A-D 前缀、选项一行内制表符分隔、判断题 N 题一组共享答案串。

## 跨电脑移植（重要）

把 **整个 `C刷题软件` 文件夹**（或压缩包）拷到另一台电脑解压即可，但目标电脑**需要安装 Python 3**：

1. 打开 https://www.python.org/downloads/ 下载 Python 3 并安装，**务必勾选「Add Python to PATH」**
2. 双击 `启动刷题软件.bat` 即可运行

启动脚本会自动定位 Python 并**验证其真的可运行**（跳过 Windows 商店「假 python 存根」，避免 9009 报错）。

## 功能

| 功能 | 说明 |
|---|---|
| **三种模式** | 顺序练习 / 错题重做 / 模拟考试 |
| **单选选项** | 自定义选项行：**未选中右侧空白**，点击后**该行整行背景变蓝**，改选即时切换 |
| **判断交互** | 先点 **✔正确 / ✘错误** 高亮选中（不锁定）→ 点**「确认答案」** 才判分，与手机版一致 |
| **🎓 模拟考试** | 右上角「开始考试」→ 20 分钟 / 20 题 / 每题 5 分；交卷出成绩 |
| **考试控制** | 考试中右上角可**暂停/继续**、**退出**；**禁止切换其他板块**（有提醒） |
| **考试中断恢复** | 强制关闭程序自动保存，下次打开**直接回到考试板块**继续；点 X 关闭有「正在考试」提醒 |
| **错题回顾** | 交卷后页面显示**错题号按钮**（每行 6 个自动换行），点击查看该题与答案 |
| **错题本** | 答错（含考试中答错）自动进入错题库；每题累计错误次数 |
| **📝 笔记** | 题目右侧笔记框；**确认答案后**才显示该题笔记；可写可改、复制粘贴、自动保存、下次显示 |
| **🗑 重置进度** | 底部「重置进度」：**连续 3 次确认 + 最后 5 秒冷静期**后才清除全部记忆 |
| **答案保密** | 题目自带答案仅存后台，作答前界面绝不出现答案 |
| **统计** | 顶部实时显示已做/总数、正确率、错题数 |

## 文件说明

```
C刷题软件/
├── core/                            程序核心代码
│   ├── 刷题软件.py                  GUI 主程序
│   ├── bank_parser.py               通用解析器（只解析单选+判断，兼容各种格式）
│   ├── build_bank.py                题库构建器（启动器缺失题库时自动调用）
│   └── update_bank.py               更新题库脚本（扫描/选择/解析/覆盖）
├── tests/                           自动化测试
│   ├── test_brust.py                自检（28 项）
│   ├── test_stress.py               压力测试（14 项）
│   ├── test_crash.py                崩溃测试（17 项）
│   ├── test_extended.py             扩展自检（23 项：数据完整性/界面结构/交互/悬停）
│   ├── test_update_bank.py          更新题库测试（17 项：解析准确性/多文档/损坏/恢复）
│   └── make_bank_fixtures.py        测试题库 Word 文档生成器
├── 题库/                            题库文档文件夹（放自带答案的 Word 题库，可多个）
│   └── 嵌入式软件开发（中级）题库（含答案）.docx
├── 题库.json                        当前生效的题库数据（可重新生成）
├── 启动刷题软件.bat                  一键启动
├── 更新题库.bat                     双击运行 → 切换题库
├── progress.json                    进度+错题次数+笔记+考试会话（自动生成，已 git 忽略）
└── README.md                        本文件（使用说明）
```
