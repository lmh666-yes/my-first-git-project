# C 语言刷题软件

> **版本：1.0.7**（2026-08-20）· 自检 22 项 / 压力 16 项 / 崩溃 14 项全部通过

基于 Word 题库（`原题目.docx` + `原题目答案.docx`）自动生成的刷题程序，界面风格类似软考通。
题库内容为 **嵌入式软件开发工程师（中级）**：单选 80 题 + 判断 50 题，共 **130 题**。

## 快速开始

1. 双击 **`启动刷题软件.bat`**（自动定位 Python；若缺 `题库.json` 会自动从 docx 生成）
2. 或命令行：`python build_bank.py` 生成题库 → `python 刷题软件.py` 打开

## 功能

| 功能 | 说明 |
|---|---|
| **四种模式** | 顺序练习 / 随机练习 / 错题重做 / 模拟考试（随机 20 题限时） |
| **单选** | 点选项 →「确认答案」→ 判对错 + 显示正确答案与解析 |
| **判断** | 点「✔正确 / ✘错误」→ 立即判分 |
| **错题记录** | 答错的题**自动进入错题库**；每题累计错误次数，作答后下方反馈框显示「本题累计错误 N 次」 |
| **📝 笔记** | 题目右侧笔记框可写入/修改笔记，自动保存到本机，下次做到该题自动显示 |
| **🗑 重置进度** | 底部「重置进度」按钮一键**清除记忆**：做题记录 / 错题次数 / 笔记全部归零，方便重新开始 |
| **统计** | 顶部显示已做/总数、正确率、错题数，进度条实时更新 |
| **收藏** | ⭐ 收藏任意题目 |
| **进度保存** | 作答记录与笔记自动保存到 `progress.json`，下次打开自动恢复 |

## 文件说明

```
C刷题软件/
├── 原题目.docx          题目（去除答案）
├── 原题目答案.docx      答案
├── build_bank.py        解析 docx → 生成 题库.json（仅单选+判断）
├── 题库.json            解析后的题库数据（可重新生成）
├── 刷题软件.py          GUI 主程序
├── 启动刷题软件.bat      一键启动
├── test_brust.py        自检（22 项）
├── test_stress.py       压力测试（16 项）
├── test_crash.py        崩溃测试（14 项）
└── progress.json        作答进度+错题次数+笔记（自动生成，已 git 忽略）
```
