# 面试题刷题软件 · 大题

> **版本：1.0.0**（2026-09-30）
> 题库：**面试题库 · 编程 / 画图大题** —— 需要**动手写代码**（函数 / 程序 / 宏 / 汇编 / 伪代码）或**看图 / 画图**（电路图、波形图、时序图、流程图）的题目，共 **131 题**
> （来源：从 `02_主观题.md` 迁出的 **33 题**（编号沿用原主观题编号 6、7、8、29…386）+「2022~2026 编程 / 画图大题汇编」**80 题**（401~480）+ 附加面试题（481~505）**18 题**；`题库/03_编程画图大题.md`）
> 编程题给参考实现；画图 / 设计题给图面要点与参考文字描述；配图（24 张）已同步到 `imgs/`。

**打字作答、不判对错**：每题输入框打字自测 → 「查看参考答案」对照 **参考实现 / 图面要点 + 得分点**。
含**模拟考试（10 题 / 40 分钟）**：交卷后逐题回顾对照答案自评；无错题库。

## 快速开始

1. 双击 **`启动刷题软件.bat`**（自动定位 Python；若缺 `题库.json` 会自动从 `题库/` 生成）
2. 或命令行：`python core/build_bank.py` 生成题库 → `python core/大题软件.py` 打开

## 功能

| 功能 | 说明 |
|---|---|
| **顺序浏览** | 上一题 / 下一题，覆盖全部 131 题 |
| **🧠 进度记忆** | 打开软件自动跳到「**连续完成题目的最后一题**」：做了 1、2、3、4，跳过 5 又做了 6、7、8，下次打开就在**第 4 题**（题头显示「↩ 已回到上次进度」）；切到考试再回来则回到刚才浏览的位置 |
| **✍️ 打字作答** | 每题输入框，**自动保存**；切题、关闭程序均不丢失 |
| **👀 查看参考答案** | 一键显示 **参考答案 + 得分点**（分色），再点「收起」隐藏 |
| **🖼 大题配图** | 电路 / 波形 / 时序图等直接显示（24 张，随题库更新自动同步；切到无图题会自动收起配图区，不占高度） |
| **跳题** | 顶栏「跳题号」输入回车：**先按题号精确跳**；题号不存在时**兑底按“第 n 题”（顺序位置）跳**；都不行时提示真实题号范围（1~505，含空档说明） |
| **⭐ 收藏** | 题目页点「⭐ 收藏」加入收藏；**取消收藏只能在「收藏」板块点「💔 取消收藏」**（带确认弹窗）；顶部统计显示收藏数；重置进度时**收藏保留** |
| **📂 分区跳转** | 顶栏「📂 分区」打开目录：左侧按来源分组的**分区树**（3 大区：①迁出题 ②2022~2026 汇编 ③附加面试题，共 29 个分区），右侧该分区**题目清单**（题号+摘要）；点题目→**弹窗确认**→自动切到顺序板块并定位；双击也可直接跳 |
| **统计** | 顶部实时显示 **已看答案 x/131 · 已作答 y/131 · ⭐收藏 n** |
| **🎓 模拟考试** | 每次 **10 题 / 40 分钟**；**环形抽题：同一场绝不重复，连续 14 场必覆盖全部 131 题**；暂停/退出/恢复；**交卷后逐题回顾**（我的作答 + 参考答案 + 得分点）自评，交卷才计入考试次数 |
| **长内容不丢** | 超长题干 / 参考答案自动增高，超限出现滚动条；窗口按屏幕自适应并居中；◀/▶ 翻题快捷键 |
| **🗑 重置进度** | 连续 3 次确认 + 最后 5 秒冷静期 |
| **不打分** | 无对错、无错题库 |

## 题库更新 / 切换

1. 把 **大题风格 md 题库**（每题带「**参考答案：**」与「**得分点：**」行）放进 **`题库/`** 文件夹
2. 双击 **`更新题库.bat`** → 自动解析并覆盖 `题库.json`
3. 重新打开刷题软件即可

> 本软件与「面试题刷题软件-主观题」共用同一份大题源文件（`面试题刷题软件-主观题/题库/03_编程画图大题.md`）。
> 改题建议改源文件后，把新文件放进本软件 `题库/` 重新「更新题库」；新题编号接**最大编号 +1**（现在最大 505）。
