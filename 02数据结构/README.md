# 02 数据结构 · C/C++ 代码可视化器

把一段 **C/C++ 代码**（链表、树、数组、递归等数据结构片段）放进来，
程序会**识别并逐步执行**，把每一步的**内存状态**（堆块、指针、箭头）
和**链表/树结构**画成图。点击左侧代码的任意一行，右侧立刻显示
**该行执行之后**的正确状态图。

## 快速开始

- **方式一**：双击 `启动可视化器.bat`
- **方式二**：命令行运行 `python visualizer.py`

打开后：

1. 顶部选择 **示例**（链表头插 / 反转 / 遍历求和、递归阶乘 / 递归链表求和、
   数组、二叉树），或点 **打开文件** 选择你自己的 `.c/.cpp` 文件，
   或点 **粘贴代码** 直接粘贴片段。
2. **点击左侧代码任意一行** → 右侧显示该行执行后的内存/结构图。
3. 点 **运行全部** → 直接跳到最终状态；点 **重置** 清空。

右侧图的组成：

- **左侧面板「调用栈 / 变量」**：每个函数一帧，列出变量名、类型与当前值
  （指针显示 `-> 0x地址`，整数显示值，数组显示元素）。
- **右侧堆区**：每个 `malloc` 出来的块是一个矩形，标注类型与地址、每个字段的值；
  指针字段用**箭头**指向它指向的块，`NULL` 用灰色文字标出。
- 若存在 `head / root / cur` 等指针，会自动按 `next / left / right` 字段
  连成 **链表 / 树形结构**，一目了然。

## 支持的语言子集（准确模拟）

| 类别 | 支持 |
|---|---|
| 类型 | `int`、`char`、`typedef struct { ... }` 结构体、指针 `*`、一维数组 `a[5]` |
| 内存 | `malloc(sizeof(T))`、`calloc(n, sizeof(T))`、`free(p)` |
| 语句 | 声明、赋值、`if/else`、`while`、`for`、`break`、`return`、`printf`（忽略） |
| 表达式 | 算术 `+ - * / %`、比较 `== != < <= > >=`、逻辑 `&& \|\| !`、取负 `-` |
| 指针 | `p->field`、`s.field`、`*p`、`&x`、`p = p->next`、下标 `a[i]` |
| 函数 | 普通函数定义与调用、**递归**（右侧显示完整调用栈） |

> 不支持的语法会**明确标红报错**（带行号），不会猜测结果，保证图正确。

## 示例：链表头插

代码（左侧）：

```c
typedef struct Node { int val; struct Node *next; } Node;
int main() {
    Node *head = NULL;
    Node *n1 = malloc(sizeof(Node));
    n1->val = 1;  n1->next = NULL;
    head = n1;
    Node *n2 = malloc(sizeof(Node));
    n2->val = 2;  n2->next = head;
    head = n2;
    return 0;
}
```

点击 `head = n2;` 那一行，右侧会画出：

```
  Node @0x1020 ──next──▶  Node @0x1000 ──next──▶  NULL
  val = 2                    val = 1
  head → 0x1020
```
