# 02 数据结构 · C/C++ 代码可视化器

> **版本：1.0.9**（2026-09-05）· 全量自动化测试通过 · 跨电脑拉取即可运行

把一段 **C/C++ 代码**（链表、树、数组、递归等数据结构片段）放进来，
程序会**识别并逐步执行**，把每一步的**内存状态**（堆块、指针、箭头）
和**链表/树结构**画成图。点击左侧代码的任意一行，右侧立刻显示
**该行执行之后**的正确状态图。

- **↩ 返回调用处**：在函数内部逐步执行时，点「返回调用处」一键跳回最外层调用者（main）的状态，

## 快速开始

- **方式一**：双击 `启动可视化器.bat`
- **方式二**：命令行运行 `python visualizer.py`

打开后：

1. 顶部选择 **示例**（链表头插 / 反转 / 遍历求和、递归阶乘 / 递归链表求和、
   数组、二叉树），或点 **打开文件** 选择你自己的 `.c/.cpp` 文件，
   或点 **粘贴代码** 直接粘贴片段。
2. **点击左侧代码任意一行** → 右侧显示该行执行后的内存/结构图。
3. 点 **运行全部** → 直接跳到最终状态；点 **重置** 清空。

右侧图的组成（上下布局，横向空间更大）：

- **上方「调用栈 / 变量」**：每个函数一帧，列出变量名、类型与当前值
  （指针显示 `-> 0x地址`，整数显示值，数组显示元素）；变量统一标注 `[栈]`。
- **下方「内存 / 结构」**：每个内存块是一个矩形，**绿色边框=栈**（局部结构体变量），
  **黄色边框=堆**（`malloc` 出来的），标题标注 `[栈]`/`[堆]` 与地址、每个字段的值；
  指针字段用**箭头**指向它指向的块，`NULL` 用灰色文字标出。
- 若存在 `head / root / cur` 等指针，会自动按 `next / left / right` 字段
  连成 **链表 / 树形结构**。

**点击代码行会显示「本行是否修改了内存」**：标题下方会用颜色标注
（如 `本行修改内存：分配[堆] Node@0x1000；声明变量 n`、`本行未修改内存（宏定义/注释等）`），
准确告诉你这一行对内存做了什么。

## 模拟输入（scanf）说明

程序含 `scanf` 时，点击 **运行全部** 或 **下一步** 遇到输入语句会弹出输入面板，
在面板中输入数据（支持空格 / 逗号 / 十六进制分隔，非法字符自动忽略），
点击 **确定** 后继续执行；输入不足时按 0 容错，不会崩溃。
支持 `scanf("%d", &a)`、`scanf("%d", a)`（教学风格）以及 `&arr[i]` / `arr[i]` 数组元素写入。

## 示例：链表头插

代码（左侧）：

```c
typedef struct Node { int val; struct Node *next; } Node;
int main() {
    Node *head = NULL;
    Node *n1 = malloc(sizeof(Node));
    n1->val = 1;  n1->next = NULL;
    head = n1;
    Node *n2 = malloc(sizeof(Node));
    n2->val = 2;  n2->next = head;
    head = n2;
    return 0;
}
```

点击 `head = n2;` 那一行，右侧会画出：

```
  Node @0x1020 ──next──▶  Node @0x1000 ──next──▶  NULL
  val = 2                    val = 1
  head → 0x1020
```
