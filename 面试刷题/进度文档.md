## 五、构建环境（本机）

- Python 3.x；JDK 17：`D:\dev-tools\jdk-17.0.20.1+1`；Android SDK：`%LOCALAPPDATA%\Android\Sdk`（含 API 35）
- 一键重建 APK：`工具\build_all_apks.bat`（**必须 clean**）；抽查：`python 工具\check_apk.py`
- 换电脑：改 `工具\build_all_apks.bat` 顶部两行 JDK/SDK 路径即可

## 六、重要约定（速查）

- **编号接最大编号 +1**：主观现 max **496**、大题现 max **530**
- 新题任何字段**禁用 `**`**（解析器会剥离）；C 二级指针写 `int * *p`；题间用 `空行 + --- + 空行`
- 大题的 `03_编程画图大题.md` 在「大题软件」与「主观题软件」题库目录**各有一份副本，必须 byte 级同步**（改完复制 + 哈希校验）
- 重复题**合并优先**，并在保留题「得分点」末尾写合并 / 互标说明；新题来源行格式：`附加面试题2.0·面试题N 基础篇第 K 题`
- 热点 = 出现率前 50% 题数（每批新题按名额标记 `**热点：** 是`）
